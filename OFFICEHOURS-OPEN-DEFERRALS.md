# Officehours — Open Deferrals (archived)

This document was the commit-level snapshot of every open deferral. It has been superseded by `BACKLOG.md`, which serves the same purpose but stays current via the `commit-msg` git hook (`.githooks/commit-msg`) — any commit referencing a backlog ID must touch `BACKLOG.md` or the commit aborts.

Read `BACKLOG.md` for the canonical view.

The original content is preserved in git history:

```bash
git log --diff-filter=A -- OFFICEHOURS-OPEN-DEFERRALS.md
git show <commit>:OFFICEHOURS-OPEN-DEFERRALS.md
```
